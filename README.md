# Kadie Fresh Website v2

A version 2 website build for the Afro food company Kadie Fresh Nig Ltd — the public marketing
site and Studio admin panel, implemented as a real Next.js + Postgres application.

- **`app/`** — the application. See `app/README.md` for setup/run instructions.
- **`DESIGN_SPEC.md`** — the full content and design specification the app was built from.
- **`project/`** and **`chats/`** — the original Claude Design prototype handoff bundle and chat
  transcript this build was implemented from, kept for reference.
